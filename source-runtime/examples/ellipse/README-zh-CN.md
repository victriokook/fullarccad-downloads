# 编辑数值椭圆范例

启动 FullArcCAD，开启 `Positioned-ellipses-demo.FCStd`，然後储存工作复本。范例包含两个 40 × 20 mm 的椭圆，拉伸厚度为 8 mm；初始中心位於 X −35/+35 mm、Y 10 mm。

在「修改参数」中将 `Gap` 从 70 改为 100 mm，中心会移到 −50/+50 mm。`Width`、`Height` 和 `CenterY` 控制两个椭圆。宽度与高度都是全长，并非半径。

若只要编辑左侧椭圆，请将其 `EllipseCenterX` 与 `EllipseWidth` 的尺寸分配设为 **固定值（无表达式）** 并套用，目前数值会保留。进入草图编辑，使用 **移动椭圆中心** 将左侧 X 设为 −50 mm，再使用 **调整椭圆大小** 将宽度设为 50 mm。保留仍连动的 Y 与高度。既有拉伸会跟着更新，右侧椭圆宽度维持不变。之後修改 `Gap` 时，只有仍连动的右侧中心会移动。

连动栏位会停用。解除两个座标的指派後，才能使用「移至原点」。座标采用草图的局部座标系。若要交换长短轴或将宽高设为相同，请重新建立椭圆。独立编辑、撤销／重做、储存後重新开启，原先均以复本验证；随附原始档维持不变。

草图中有多个椭圆时，先选取一个支援的轮廓再开启编辑器，该椭圆会成为初始目标。建构轴与一般椭圆不算数值椭圆的选取项目。若选取多个支援的轮廓，会使用清单中的第一项。
