# 수치 타원 예제 편집

FullArcCAD를 실행한 다음 `Positioned-ellipses-demo.FCStd`를 열고 작업 복사본을 저장하세요. 이 예제에는 40 × 20 mm 타원 두 개가 8 mm 두께로 돌출되어 있습니다. 초기 중심은 X −35/+35 mm, Y 10 mm입니다.

「매개변수 변경」에서 `Gap`을 70 mm에서 100 mm로 바꾸면 중심이 −50/+50 mm로 이동합니다. `Width`, `Height`, `CenterY`는 두 타원에 공통으로 적용됩니다. 너비와 높이는 반지름이 아니라 전체 길이입니다.

왼쪽 타원만 편집하려면 `EllipseCenterX`와 `EllipseWidth`의 치수 할당을 **고정값（수식 없음）**으로 설정하고 적용하세요. 현재 값은 유지됩니다. 스케치 편집에서 **타원 중심 이동**으로 왼쪽 X를 −50 mm로 설정하고, **타원 크기 조정**으로 너비를 50 mm로 설정하세요. 연동된 Y와 높이는 그대로 두세요. 기존 돌출은 갱신되고 오른쪽 타원의 너비는 유지됩니다. 이후 `Gap`을 변경하면 여전히 연동된 오른쪽 중심만 이동합니다.

연동된 필드는 비활성화됩니다. 두 좌표의 연결을 모두 해제하면 「원점으로 이동」을 사용할 수 있습니다. 좌표는 스케치의 로컬 좌표입니다. 장축과 단축을 바꾸거나 너비와 높이를 같게 하려면 타원을 다시 만드세요. 개별 편집, 실행 취소/다시 실행, 저장 후 다시 열기는 원래 복사본에서 검증되었으며 제공된 원본은 변경되지 않습니다.

타원이 여러 개라면 스케치 편집 중 지원되는 윤곽선 하나를 선택한 뒤 편집기를 열어 초기 대상을 지정하세요. 구성 축과 일반 타원은 수치 타원 선택으로 취급하지 않습니다. 지원되는 윤곽선을 여러 개 선택하면 목록의 첫 번째 항목을 사용합니다.
