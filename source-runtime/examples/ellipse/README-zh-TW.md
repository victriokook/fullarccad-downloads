# 編輯數值橢圓範例

啟動 FullArcCAD，開啟 `Positioned-ellipses-demo.FCStd`，然後儲存工作複本。範例包含兩個 40 × 20 mm 的橢圓，引伸厚度為 8 mm；初始中心位於 X −35/+35 mm、Y 10 mm。

在「變更參數」中將 `Gap` 從 70 改為 100 mm，中心會移到 −50/+50 mm。`Width`、`Height` 和 `CenterY` 控制兩個橢圓。寬度與高度都是全長，並非半徑。

若只要編輯左側橢圓，請將其 `EllipseCenterX` 與 `EllipseWidth` 的尺寸指派設為 **固定值（無運算式）** 並套用，目前數值會保留。進入草圖編輯，使用 **移動橢圓中心** 將左側 X 設為 −50 mm，再使用 **調整橢圓大小** 將寬度設為 50 mm。保留仍連動的 Y 與高度。既有引伸會跟著更新，右側橢圓寬度維持不變。之後修改 `Gap` 時，只有仍連動的右側中心會移動。

連動欄位會停用。解除兩個座標的指派後，才能使用「移至原點」。座標採用草圖的局部座標系。若要交換長短軸或將寬高設為相同，請重新建立橢圓。獨立編輯、復原／重做、儲存後重新開啟，原先均以複本驗證；隨附原始檔維持不變。

草圖中有多個橢圓時，先選取一個支援的輪廓再開啟編輯器，該橢圓會成為初始目標。建構軸與一般橢圓不算數值橢圓的選取項目。若選取多個支援的輪廓，會使用清單中的第一項。
