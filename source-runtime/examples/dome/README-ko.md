# 중공 돔 예제

FullArcCAD를 실행한 다음 `Hollow-dome-demo.FCStd`를 열고 작업 복사본을 저장하세요. 초기 치수는 바닥면 30 × 42 mm, 높이 12 mm, 벽 두께 1 mm이며 바닥은 열려 있습니다.

「매개변수 변경」에서 `BaseX`, `BaseY`, `DomeRise`, `Wall`을 조정하세요. `Wall`을 0 mm로 설정하면 속이 꽉 찬 돔이 됩니다. 매개변수에 연결된 필드는 치수 편집기에서 비활성화됩니다. 개별적으로 편집하려면 「치수 할당」에서 「고정값（수식 없음）」을 선택하고 적용하세요. 연결을 해제해도 현재 값은 유지됩니다.

재료 부피는 실제 미리보기 형상을 기준으로 mm³ 단위로 계산하며 빈 공간은 제외합니다. 무게를 뜻하지 않습니다. 치수를 바꾸면 갱신되며 유효하지 않은 미리보기에서는 표시하지 않습니다. 치수를 조정할 때 표시되는 벽 두께 상한을 확인하세요.

위치 X/Y/Z는 바닥면 중심의 위치를 정합니다. 기존 모델을 편집할 때는 회전 방향이 유지됩니다. 상위 Part 안의 위치는 해당 Part의 좌표계를 따릅니다. 「취소」하면 미리보기가 제거되고 원본의 표시 상태가 복원됩니다.
