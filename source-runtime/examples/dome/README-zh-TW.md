# 中空圓頂範例

啟動 FullArcCAD，開啟 `Hollow-dome-demo.FCStd`，並儲存工作複本。初始尺寸為底面 30 × 42 mm、高度 12 mm、壁厚 1 mm，底部開口。

在「變更參數」中調整 `BaseX`、`BaseY`、`DomeRise` 和 `Wall`。將 `Wall` 設為 0 mm 可建立實心圓頂。尺寸編輯器中由參數控制的欄位會停用。若要獨立編輯，請在「尺寸指派」中選擇「固定值（無運算式）」並套用；目前數值會保留。

材料體積根據實際預覽形狀計算，單位為 mm³，不包含中空部分，也不是重量。尺寸變更時會更新；預覽形狀無效時不顯示。調整尺寸時請參考畫面上的壁厚上限。

位置 X/Y/Z 決定底面中心的位置；編輯時會保留原有旋轉。在父層 Part 內的位置採用父層座標系。「取消」會移除預覽並恢復原始模型的顯示狀態。
