# 中空圆顶范例

启动 FullArcCAD，开启 `Hollow-dome-demo.FCStd`，并储存工作复本。初始尺寸为底面 30 × 42 mm、高度 12 mm、壁厚 1 mm，底部开口。

在「修改参数」中调整 `BaseX`、`BaseY`、`DomeRise` 和 `Wall`。将 `Wall` 设为 0 mm 可建立实心圆顶。尺寸编辑器中由参数控制的栏位会停用。若要独立编辑，请在「尺寸分配」中选择「固定值（无表达式）」并套用；目前数值会保留。

材料体积根据实际预览形状计算，单位为 mm³，不包含中空部分，也不是重量。尺寸变更时会更新；预览形状无效时不显示。调整尺寸时请参考画面上的壁厚上限。

位置 X/Y/Z 决定底面中心的位置；编辑时会保留原有旋转。在父层 Part 内的位置采用父层座标系。「取消」会移除预览并恢撤销始模型的显示状态。
