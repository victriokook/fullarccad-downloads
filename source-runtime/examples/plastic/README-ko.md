# 플라스틱 케이스: 편집부터 내보내기까지

FullArcCAD를 실행한 다음 예제를 열고 작업 복사본을 저장하세요. `Parametric-enclosure.FCStd`는 보스, 관통 구멍, 삼각 리브, 스냅 후크의 치수 연동을 보여 줍니다. `Drafted-enclosure.FCStd`는 보스에 구배를 추가합니다. `Instanced-enclosures.FCStd`는 배치된 두 구성요소가 같은 케이스를 공유합니다. `Tapered-rib-demo.FCStd`는 리브와 보스의 구배 및 스냅 높이 연동을 보여 줍니다.

파라메트릭 예제의 「매개변수 변경」에서 `BossHeight`를 18 mm로 설정하세요. 연동된 스냅 높이는 20 mm가 됩니다. 실행 취소/다시 실행으로 둘을 함께 복원할 수 있습니다. 저장 후 다시 열어도 치수와 수식이 유지됩니다.

「관리」에서 STEP/STL을 내보내세요. 현재 표시된 형상이 내보내기에 포함되므로 이력의 중간 피처를 확인하고 있다면 최종 피처의 표시 상태를 먼저 확인하세요. 「설계 → 렌더링」에서 등각 투영 PNG를 만들 수 있습니다. 원래 검증된 절차에서는 이미지 생성 중 시점, 선택, 표시 상태, 이력이 유지되며 STEP을 다시 가져왔을 때 재료 부피와 외곽 치수가 일치합니다. 플라스틱 피처는 이력에서 편집하고, 연동된 필드는 「매개변수 변경」에서 조정하세요.
