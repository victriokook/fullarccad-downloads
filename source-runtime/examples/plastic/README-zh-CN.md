# 塑胶外壳：从编辑到汇出

先启动 FullArcCAD，再开启范例并储存工作复本。`Parametric-enclosure.FCStd` 示范凸柱、贯穿孔、三角肋与卡扣的尺寸连动。`Drafted-enclosure.FCStd` 加入凸柱拔模斜度；`Instanced-enclosures.FCStd` 以两个不同位置的元件共用外壳；`Tapered-rib-demo.FCStd` 示范肋与凸柱的拔模斜度及卡扣高度连动。

在参数化外壳范例的「修改参数」中，将 `BossHeight` 设为 18 mm；连动的卡扣高度会变为 20 mm。撤销／重做会一并恢复两者。储存後重新开启，尺寸与表达式仍会保留。

从「管理」汇出 STEP/STL。汇出内容包含目前显示的几何，因此检视历程中间特徵时，请先确认最终特徵的显示状态。从「设计 → 渲染」可产生等角视图 PNG。原先验证的流程会在产生影像时保留视角、选取、显示状态及历程；重新汇入 STEP 的材料体积与外形尺寸也一致。可从历程编辑塑胶特徵；连动栏位请在「修改参数」中调整。
