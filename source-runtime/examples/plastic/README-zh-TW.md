# 塑膠外殼：從編輯到匯出

先啟動 FullArcCAD，再開啟範例並儲存工作複本。`Parametric-enclosure.FCStd` 示範凸柱、貫穿孔、三角肋與卡扣的尺寸連動。`Drafted-enclosure.FCStd` 加入凸柱拔模斜度；`Instanced-enclosures.FCStd` 以兩個不同位置的元件共用外殼；`Tapered-rib-demo.FCStd` 示範肋與凸柱的拔模斜度及卡扣高度連動。

在參數化外殼範例的「變更參數」中，將 `BossHeight` 設為 18 mm；連動的卡扣高度會變為 20 mm。復原／重做會一併恢復兩者。儲存後重新開啟，尺寸與運算式仍會保留。

從「管理」匯出 STEP/STL。匯出內容包含目前顯示的幾何，因此檢視歷程中間特徵時，請先確認最終特徵的顯示狀態。從「設計 → 彩現」可產生等角視圖 PNG。原先驗證的流程會在產生影像時保留視角、選取、顯示狀態及歷程；重新匯入 STEP 的材料體積與外形尺寸也一致。可從歷程編輯塑膠特徵；連動欄位請在「變更參數」中調整。
