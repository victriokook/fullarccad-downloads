# FullArcCAD source

FullArcCAD is an open-source FreeCAD add-on with a Fusion 360–style modeling workflow. Project-managed code and assets are MIT licensed. See LICENSE and OPEN-SOURCE.md for scope and third-party notices.

Install FreeCAD separately. In FreeCAD, open Macro → Macros, choose this folder as the macro directory, and run FullArcCAD.FCMacro. The source entry point is tested with 64-bit FreeCAD and embedded Python 3.11. Choose Settings → Language and restart to switch the interface language.

The source includes the independent sheet metal preview 41 implementation and the mirrored-body Combine fix. Newer independent sheet metal dialogs have Japanese/English text. The main interface has ten language catalogs. Known preview limits are described in INDEPENDENT-SHEETMETAL.md.
